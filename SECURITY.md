# Seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades de seguridad en issues, pull requests ni discusiones públicas. Envía un reporte privado a los mantenedores del repositorio mediante [GitHub Security Advisories](https://github.com/open-ucsh/web-modelador-bd/security/advisories/new), si está habilitado, o contacta a la organización [Open UCSH](https://github.com/open-ucsh).

Incluye, cuando sea posible:

- Descripción y posible impacto.
- Pasos mínimos para reproducir el problema.
- Versión o commit afectado.
- Navegador, sistema operativo y configuración relevante.
- Una propuesta de mitigación, si la conoces.

No incluyas datos privados de estudiantes, diagramas confidenciales, credenciales ni tokens.

## Alcance de seguridad

MER Designer guarda los proyectos en el almacenamiento local del navegador y no debe tratarse como un sistema de almacenamiento seguro o de respaldo. No introduzcas secretos en diagramas, archivos JSON exportados ni capturas de pantalla.

Las vulnerabilidades confirmadas se corregirán priorizando el impacto y se comunicará la solución cuando sea seguro hacerlo.
