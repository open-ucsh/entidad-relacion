# Ayuda y soporte

## Antes de pedir ayuda

Consulta primero:

- [Guía de uso](./docs/usage.md)
- [Notación ER](./docs/er-notation.md)
- [Ejercicios prácticos](./docs/practice/README.md)
- [Issues existentes](https://github.com/open-ucsh/web-modelador-bd/issues)

## Dónde preguntar

- Usa un issue para bugs reproducibles o propuestas de mejora.
- Usa una discusión para preguntas generales, ideas y decisiones de producto, si las discusiones están habilitadas.
- Para vulnerabilidades, sigue [`SECURITY.md`](./SECURITY.md) y no abras un issue público.

## Qué incluir en un bug

Describe qué intentabas hacer, los pasos para reproducirlo, qué esperabas, qué ocurrió, navegador y dispositivo. Si es posible, adjunta un proyecto JSON mínimo que no contenga información sensible.
