# Notación ER

La notación Entidad–Relación permite representar visualmente la estructura de una base de datos antes de crear tablas o escribir código.

- 🟦 **Entidad:** representa algo que existe, como `Estudiante`, `Curso` o `Libro`.
- 🟪 **Relación:** muestra cómo se conectan las entidades, por ejemplo `Estudiante` **se inscribe en** `Curso`.
- 🟢 **Atributo:** describe una propiedad, como `nombre`, `correo` o `fecha`.
- 🔑 **Clave primaria:** identifica de forma única cada registro.
- 🔗 **Cardinalidad:** indica cuántos elementos participan en una relación: `1:1`, `1:N` o `N:M`.
