# 01 — Biblioteca 📚

**Inicial · Entidades, relaciones y atributos**

Una biblioteca quiere reemplazar su registro en papel por un sistema digital. Necesita mantener información de sus libros —título, ISBN, autor y año de publicación— y de las personas inscritas, incluyendo su nombre, correo y número de registro. También debe registrar cada préstamo, con su fecha de inicio y devolución, considerando que un libro puede ser solicitado muchas veces a lo largo del tiempo, pero no por dos personas al mismo tiempo.

💡 No hay una única forma correcta de modelarlo. Construye una propuesta clara y que tenga sentido.
