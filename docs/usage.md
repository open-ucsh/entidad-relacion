# Uso del editor

## ✨ Crea tu diagrama

Elige una herramienta en la barra lateral y haz clic en el lienzo para agregar elementos.

Arrástralos para moverlos. Para seleccionar varios, arrastra sobre un área vacía o mantén `Shift` al seleccionar.

Usa las opciones de alineación y distribución para mantener todo ordenado.

## 🎨 Edita elementos

Selecciona un elemento para abrir sus propiedades en el inspector.

Puedes cambiar su nombre, tipo, colores y opciones. También puedes editar una conexión seleccionándola.

Duplica un elemento con `Ctrl` + `D`.

## 💾 Gestiona proyectos

Tu trabajo se guarda automáticamente en el almacenamiento local del navegador.

Puedes tener hasta **4 proyectos** guardados y usar el historial para revisar, deshacer o rehacer cambios.

## 📤 Exporta

Exporta tu diagrama como **JSON** para guardarlo, compartirlo o importarlo después.

También puedes descargarlo como **PNG, JPEG o PDF** cuando esté listo.
